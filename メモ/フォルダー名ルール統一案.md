# フォルダー名ルール統一案

**対象:** 個人マイドライブ全体のフォルダ名  
**更新:** 2026-08-12  
**状態:** ルール骨子はユーザー確定。改名は未実施（家の Mac）。

---

## 正式ルール（確定）

### 基本形

```
{番号}_{名前}
```

- 区切りは常に `_`。`)` と `★` は使わない
- **番号は親の番号を継承して桁を伸ばす**

### 桁の伸ばし方

| 階層 | 形 | 例 |
|------|-----|-----|
| ルート | 2桁 | `20_生活・家庭` |
| その直下 | 3桁 | `201_稲垣書類`, `204_自動車` |
| さらに下 | 4桁 | `2011_督書類`, `2041_保険` |
| その下 | 5桁 | `20111_契約書・保証書` など |

### 触らない・例外

| フォルダ | 扱い |
|----------|------|
| `99_開発・プロンプト` | **改名・移動しない** |
| `00_Inbox` | 維持 |
| ルート `Google AI Studio` | **ルートに残す**（`901` はルートへ統合して削除） |
