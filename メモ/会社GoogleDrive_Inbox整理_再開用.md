3. ローカルエージェントに「会社ファイルを移動させて」と送る  
   またはターミナルで:

```bash

python3 scripts/move_drive_inbox.py --dry-run
python3 scripts/move_drive_inbox.py --execute
```

4. Inbox が空になったら完了。このメモの状態を「移動済み」に更新
