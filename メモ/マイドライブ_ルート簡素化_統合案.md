## 2. 自動車まわりを一箇所にまとめる

### いま散らばっている場所（スクショ）

- `201) 稲垣書類 / 211) 自動車保険_20260612`
- `★1督書類 / ★1-4 自動車関連`
- `★1-1 契約書・保証書` 内の自動車関係

### 提案（行き先を1つにする）

| 案 | まとめ先 | 中の分け方 |
|----|----------|------------|
| **A（推奨）** | `201_稲垣書類 / 2013_自動車` | `01_保険` / `02_契約・保証` / `03_その他` |
| **B** | `2011_督書類 / 20114_自動車` | 督書類の中に閉じる |
| **C** | `20_…` 直下に `204_自動車` | 書類親から独立 |

**A のときやること**

1. `211) 自動車保険_…` の中身 → `2013_自動車 / 01_保険`
2. `★1-4 自動車関連` の中身 → `2013_自動車`（保険以外は `03_その他` など）
3. `★1-1 契約書・保証書` から自動車関連だけ抜き出し → `2013_自動車 / 02_契約・保証`
4. 空になった `★1-4` / `211)` は削除
5. 契約書フォルダは自動車以外の契約だけ残す

→ **A / B / C どれ？** 契約書から抜く基準（車検証・任意保険・ローン等）で迷うものは Inbox に一時退避でも可。

## 3. 学習まわりを一箇所にまとめる

### 提案

| 種類 | 行き先 |
|------|--------|
| 司法試験の復習・理解メモ | `10_司法試験`（ルートの `.gdoc` 3件もここ） |

→ 公的書類だけ残すならその旨を指示。
